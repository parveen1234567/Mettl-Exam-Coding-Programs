# Mettl Exam Coding Programs

A collection of standalone Java programs covering common coding-exam problems, number operations, arrays, and strings.

## Programs

### Numbers and sequences

- `AdamNumber.java` - Adam number check
- `ArmstrongNumber.java` - Armstrong number check
- `CollatzSequence.java` - Collatz sequence
- `EvenPalindromeNumber.java` - Even palindrome number check
- `FibonacciSeries.java` - Fibonacci series
- `IncreasingDigitNumbers.java` - Increasing-digit number check
- `KaprekarNumber.java` - Kaprekar number check
- `NthFibonacciNumber.java` - Find the nth Fibonacci number
- `OddPalindromeNumber.java` - Odd palindrome number check
- `PalindromeNumber.java` - Palindrome number check
- `PrimeNumberCheck.java` - Prime number check
- `QuadraticEquation.java` - Solve a quadratic equation
- `StrongNumber.java` - Strong number check
- `SumofDigitsUntilSingleDigit.java` - Sum digits until one digit remains

### Arrays

- `MajorityElement.java` - Find a majority element
- `MissingNumber.java` - Find a missing number
- `MoveAllZerostoEnd.java` - Move zeroes to the end
- `RemoveDuplicateElements.java` - Remove duplicate elements
- `SecondLargestElement.java` - Find the second-largest element

### Strings and characters

- `AnagramCheck.java` - Check whether two strings are anagrams
- `CharacterFrequency.java` - Count character frequencies
- `CountVowelsandConsonants.java` - Count vowels and consonants
- `LongestWordinaSentence.java` - Find the longest word in a sentence
- `MatchingParentheses.java` - Check matching parentheses
- `ReverseWords.java` - Reverse words in a string
- `StringCompression.java` - Compress a string

## Compile and run

Install a Java Development Kit (JDK), then compile the programs from this directory:

```bash
javac *.java
```

Each source file is a standalone program. Run a program using its class name as declared in the corresponding `.java` file:

```bash
java <ClassName>
```
